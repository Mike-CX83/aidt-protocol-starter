# Contributing to AIDT / HHP

1) Fork and create a feature branch.  
2) Run `make validate` before opening a PR.  
3) If you modify `PRD.yaml` or `BUILDPLAN.yaml`, include a matching handshake decision (`A3.decision.yaml`) in your PR.  
4) Add or update ADRs when changing architecture.

We welcome docs, templates, and adapters for IDEs and LLMs.
