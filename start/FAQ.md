# FAQ

**Q: I don’t see agents A1/A2.**  
A: Run the Agent‑3 autoboot prompt; it creates them from templates.

**Q: Plans changed without approval?**  
A: They shouldn’t — A3 must write a decision; CI can block unapproved changes.

**Q: Which files should I pin in the IDE?**  
A: Each agent’s `STATE.yaml` plus `BUILDPLAN.yaml` and `PRD.yaml`.
